# Handoff template

Record task ID/title, UTC, outcome, checkpoint revision, source ref/SHA/status, entry baseline,
precise changed paths, implemented and pending workstreams, exact QA commands/exit/SHA,
unrun checks and why, reopened/known failures, preservation evidence, relative local evidence,
source delivery/remote equality, handoff publication, operator acceptance and one NEXT_EXACT_ACTION.
Allowed outcomes are COMPLETE_VERIFIED, PARTIAL, INTERRUPTED, BLOCKED and CHECKPOINT.
Keep each immutable history entry. Local handoffs are HANDOFF_NOT_PUBLISHED.
