# Session Workflow

## NEW_TASK

Fingerprint source, check protected changes and nearest instructions, route ownership, record authorized scope. Use MAX POWERBRAIN for cross-system or risky work.

## RESUME_ACTIVE_OR_INTERRUPTED

Use the checkpoint for ACTIVE, INTERRUPTED and PARTIAL after comparing task authorization, branch, SHA and recorded source fingerprint against doctor. On mismatch VERIFY_FIRST. COMPLETE starts a new task. BLOCKED requires evidence of unblock.

## HIGH_RISK_ESCALATION

Identify earliest authoritative boundary, ownership, affected data and rollback. Escalate unresolved permission, schema, migration, generated-data and cross-subsystem risks. Finish unaffected work.

## CLOSEOUT

Verify targeted and preservation gates. Update durable docs at the right cadence. Write checkpoint and report with exact source, commands, exit codes, open gates and one next action.

## Context pressure and checkpoints

At estimated 70–80% finish the atomic step and checkpoint. At 80–90% avoid starting broad work and record an INTERRUPTED handoff with evidence. Checkpoint periodically before crashes can occur.

## Reopened bug / false PASS escalation

Reopen gate on operator reproduction. Compare failing input, prior proof and first writer/reader divergence; retain old evidence and rerun negative control.

## Grand Master and derived context update laws

Update master for durable ownership, decisions, invariants, architecture and lessons. Update current state when actual source or milestone changes. Keep index and owner map bounded and append evidence to history.

## Exact next action and zero-chat restore

Record one concrete command or specific file and step. A new agent needs AGENTS, actual doctor state, five rules, current state, checkpoint, handoff and indexed source only.
