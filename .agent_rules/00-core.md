# Core Authority

## Product and verified scope

Roadside Drive is intended as a modular driving simulation. Observed product entry is the local Unreal descriptor and default configs. Phase 1 intent is an editable, georeferenced Banja Luka street segment of 500–1000 m. The world generator and product acceptance are open.

## Permission boundaries and explicit operator approval

UAOS-B1 is project-scoped. Obtain product scope, and separate authority for migrations, CI privileges and deployment. Routine repository publication and authorized refs follow the standing [publication policy](30-evidence-and-publication.md). Check the actual destination and file inventory before publication.

## Source/Git precedence; source facts vs intended behavior

Operator authorization defines scope. Live source/Git and direct observations establish facts. The approved master defines intended invariants, native evidence establishes tested runtime behavior, and archived handoffs provide historical evidence.

## Actual runtime / anti-false-PASS

Reopen any affected gate on an operator-reproduced failure. Label assumptions HYPOTHESIS or VERIFY_FIRST. Distinguish static checks, native runtime proof and explicit operator acceptance.

## Canonical Grand Master and derived layers

Use the manifest's single master and route via the index. Current state and handoffs cannot supersede the source or approve scope.

## No assumptions about branch, tool, stack or release

Re-read the actual ref, SHA, status, prerequisites and remote policy every session.
